  checks authority identity, protocol membership, readiness and checkpoint
  context. Malformed entries and unavailable observations fail explicitly.
- Synthetic deadlines include full body reads, parsing and safe-read retries.
  Transport errors preserve any received HTTP status without inventing a 504.
  Writes do not retry; streamed smoke responses have a 16 MiB limit.
- Browser smoke installs the locked Chromium and requires a launch/close
  preflight before collecting page verdicts.
- Navigation and screenshot failures now fail the visual harness instead of
  allowing an exit code of zero after a closed browser.
- Oversized transaction/outpoint batches fail explicitly instead of silently
  dropping inputs. Existing callers continue their bounded batching.
- History coverage displays current unavailability separately from retained
  coverage, including the v2 health contract used by Dogecoin.
- Mining subscriptions stop at component destruction. Difficulty widgets use
  bounded loading, error and retry states rather than anonymous skeletons.
- Taproot tree validation remains available through the address feature while
  its elliptic-curve dependency leaves the initial shared transaction bundle.
- Collaborative package verification, node artifact verification and consensus
  campaign/replay no longer manufacture successful proof or execution results.
  Invalid inputs receive 400; missing verifier/trust/runner dependencies receive
  503. These integrations are still incomplete, not accepted operations.
- The bootstrap planner no longer substitutes invented timing estimates when
  its backend request fails.
- BOLT12 labels use the returned validity field, RFQ expiry uses its actual
  timestamp, and failed reads display an error. Seeded offer and RFQ producers
  remain unresolved; these presentation repairs do not verify their authority.
- Taproot Assets no longer treats a long string as a verified proof or returns
  an invented root and anchor height. Malformed input returns 400; a missing
  actual verifier returns 503 with `valid: false`.
