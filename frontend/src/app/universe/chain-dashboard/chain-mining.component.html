How {{ profile.name }} mining works

Dogecoin uses scrypt proof of work with a 60 second target and, since block 371,337, allows merged mining through AuxPoW: a Litecoin miner embeds a commitment to a Dogecoin block in its Litecoin work, so one round of hashing can win both chains.

The block subsidy has been a fixed 10,000 DOGE per block since block 600,000. There is no halving schedule; supply grows by roughly 5 billion DOGE per year.

Pool attribution reads the Dogecoin coinbase and, where present, the AuxPoW parent chain's coinbase tag. Merged-mining pools usually tag the parent chain, so attribution here is only as strong as that evidence.

Zcash uses Equihash proof of work with a 75 second target since the Blossom upgrade. Miner capacity is measured in solutions per second.

The block subsidy halves on a schedule; part of each subsidy is directed by consensus to development funds and, since NU6, to a lockbox. The subsidy shown here is the miner's share as the node reports it.

Pool attribution reads the transparent coinbase only. Shielded coinbase outputs carry no attribution evidence, so more Zcash blocks stay Unknown than on transparent chains.
