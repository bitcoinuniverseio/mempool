Check the outputs before spending them

This page reads the base chain only, so it cannot say which of these outputs carry an inscription, a rune, or any other protocol asset. That is why it lists all of them rather than a chosen few. Spending or replacing an output that carries something can destroy it.

What this page will not do

  • It does not build a transaction. It produces the numbers a wallet needs and stops there.
  • It cannot sign. No key reaches this page.
  • It does not promise confirmation. A rate is a bid, and a block is whatever a miner chooses to build.
  • Every figure is against this node's own policy, read from it rather than assumed. Another node may hold a different one.
