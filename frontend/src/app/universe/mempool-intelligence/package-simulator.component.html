What this page will not do

  • It does not broadcast. Testing a package and sending one are different actions, and this page only does the first.
  • It cannot sign, and refuses anything that looks like key material.
  • It does not promise confirmation. A verdict is what one node would do with a package now, not what the network will do with it.
  • It does not fill a gap with a guess. A fee this node cannot work out is reported as unknown, and no total that depends on it is claimed.
