What this page will not show

  • No peer address, on any network. That is this node's topology, and publishing it hands an attacker the list of peers to go after.
  • None of the node's own addresses. On a host behind a tunnel those are exactly what the tunnel exists to keep private.
  • Nothing about the process running the node: no log path, no configuration, no credential, no filesystem layout.
  • Nothing that could change the node. There is no control here to find, because the server has no route that would accept one.
