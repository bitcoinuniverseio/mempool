Why this is safe to leave open

  • The server holds a list of the methods it will call. A method absent from that list has no path to a call at all, so nothing new becomes reachable when the node gains a method.
  • No name from a request is ever turned into a call. A name is matched against the list first, and it is the list's own entry that is invoked.
  • Every argument is checked against a declared shape, and an argument past the last declared one is refused rather than dropped.
  • Some read only methods are still kept out: those that describe the process rather than the chain, and those whose cost is unbounded.
  • Each method has a budget per minute, so this cannot be used to make the node's time somebody else's.
