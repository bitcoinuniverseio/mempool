What this page will not do

  • It cannot sign. There is no signing code on this page and no key ever reaches it.
  • It sends nothing. Reading a file here makes no request of any kind. The site navigation around this page loads as it does everywhere, and what you paste is never part of it.
  • It stores nothing. Leaving the page discards whatever was in the boxes.
  • It alters nothing. What it reads, it can write back byte for byte.
